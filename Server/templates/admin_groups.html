Nutzergruppen

Gruppen steuern den Zugriff auf Notizen über Queries.
Eine Gruppe kann eine Query hinterlegen, die bestimmt, welche Notizen ihre Mitglieder sehen dürfen.

Query-Syntax (eine Bedingung pro Zeile, alle müssen zutreffen):
feld = wert  ·  feld != wert  ·  feld contains text  ·  feld starts_with prefix
Spezialfelder: tag, path, title — alle anderen Felder beziehen sich auf Frontmatter-Keys.
Beispiele: tag = premium  ·  path starts_with "Projekt/"  ·  published = true
