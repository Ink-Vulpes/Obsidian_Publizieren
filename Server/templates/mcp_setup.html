MCP Setup

KI-Zugriff auf deinen Vault via Model Context Protocol

Was ist MCP?

Das Model Context Protocol (MCP) ist ein offener Standard von Anthropic, der es KI-Assistenten wie Claude ermöglicht, direkt auf externe Datenquellen zuzugreifen. Mit dieser Schnittstelle kann Claude Notizen aus deinem Vault lesen, durchsuchen und für Analysen, Zusammenfassungen oder Fragen nutzen.

Schritt 1 – API-Token generieren

Generiere einen langlebigen Token (1 Jahr Laufzeit), den du in deiner Claude-Desktop-Konfiguration hinterlegst. Der Token wird mit deinen Rechten ausgestellt – du siehst nur Notizen, auf die du Zugriff hast.

Bewahre diesen Token sicher auf – er wird nicht gespeichert.

Schritt 2 – Claude Desktop konfigurieren

Öffne deine Claude Desktop Konfigurationsdatei:

  • macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
  • Windows: %APPDATA%\Claude\claude_desktop_config.json

Füge folgenden Eintrag in den mcpServers-Block ein (ersetze DEIN_TOKEN mit dem generierten Token und passe die URL an):

{
  "mcpServers": {
    "obsidian-vault": {
      "url": "{{ base_url }}/mcp",
      "headers": {
        "Authorization": "Bearer DEIN_TOKEN"
      }
    }
  }
}

Nach dem Speichern Claude Desktop neu starten. Der Vault erscheint dann als verfügbares Tool.

Schritt 3 – Verfügbare Tools

Nach der Verbindung stehen Claude folgende Tools zur Verfügung:

search_notes

Volltextsuche über Titel und Inhalt aller Notizen. Gibt bis zu 20 Treffer mit Auszug zurück.

search_notes(query: "Zellbiologie")
read_note

Liest den vollständigen Markdown-Inhalt einer Notiz anhand ihres Slugs.

read_note(slug: "01 MOC/Index")
list_notes

Listet alle sichtbaren Notizen mit Titel, Slug und Tags (Standard: max. 100).

list_notes(limit: 50)

Die Gruppenrechte werden automatisch angewendet – Claude sieht nur Notizen, auf die dein Account Zugriff hat.

Beispiel-Prompts für Claude

  • „Fasse alle Notizen über Zellbiologie zusammen."
  • „Welche Notizen haben das Tag #Abitur?"
  • „Erkläre mir den Inhalt der Notiz Mitose."
  • „Was sind die Verbindungen zwischen meinen Notizen über Photosynthese?"
