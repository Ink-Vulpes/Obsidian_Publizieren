MCP Setup

KI-Zugriff auf diesen Vault via Model Context Protocol

Was ist MCP?

Das Model Context Protocol (MCP) ist ein offener Standard, der von Anthropic entwickelt und am 25. November 2024 als Open-Source-Projekt veröffentlicht wurde. Es standardisiert, wie KI-Assistenten (große Sprachmodelle) auf externe Daten und Tools zugreifen.

Vor MCP musste für jede Kombination aus KI-Modell und Datenquelle eine eigene Schnittstelle gebaut werden – das sogenannte M×N-Integrationsproblem. MCP löst das mit einer universellen, modellunabhängigen Schnittstelle auf Basis von JSON-RPC 2.0:

HostDein KI-Assistent
(Claude, ChatGPT …)
→
MCP ClientEingebaut im Host
→
MCP ServerDieser Vault
(/mcp Endpunkt)

Inzwischen unterstützen alle großen KI-Anbieter MCP – darunter OpenAI, Google DeepMind und Microsoft. MCP-Server können lokal (stdio) oder remote (HTTP) betrieben werden. Dieser Vault läuft als HTTP-Server und ist damit von jedem MCP-kompatiblen Client aus erreichbar.

Schritt 1 – API-Token generieren

Generiere einen langlebigen Token (1 Jahr Laufzeit), den du in deiner Agent-Konfiguration hinterlegst. Der Token wird mit deinen Rechten ausgestellt – du siehst nur Notizen, auf die dein Account Zugriff hat.

Bewahre diesen Token sicher auf – er wird nicht gespeichert.

Schritt 2 – Agent konfigurieren

Wähle deinen KI-Assistenten und folge der Anleitung. Der generierte Token aus Schritt 1 wird in allen Fällen benötigt.

C Claude Desktop Empfohlen

Öffne deine Claude-Desktop-Konfigurationsdatei:

  • macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
  • Windows: %APPDATA%\Claude\claude_desktop_config.json

Füge folgenden Eintrag in den mcpServers-Block ein:

{
  "mcpServers": {
    "obsidian-vault": {
      "url": "{{ base_url }}/mcp",
      "headers": {
        "Authorization": "Bearer DEIN_TOKEN"
      }
    }
  }
}

Claude Desktop neu starten. Der Vault erscheint danach als verfügbares Tool.

G OpenAI ChatGPT Desktop

ChatGPT Desktop (ab Version 1.2025.x) unterstützt MCP-Server. Öffne die Konfigurationsdatei:

  • macOS: ~/Library/Application Support/com.openai.chat/mcp.json
  • Windows: %APPDATA%\OpenAI\ChatGPT\mcp.json

Erstelle oder ergänze die Datei mit:

{
  "mcpServers": {
    "obsidian-vault": {
      "url": "{{ base_url }}/mcp",
      "headers": {
        "Authorization": "Bearer DEIN_TOKEN"
      }
    }
  }
}

ChatGPT neu starten. Der Vault ist dann als Tool in Gesprächen verfügbar.

M Microsoft 365 Copilot

Für Microsoft 365 Copilot wird ein eigener Copilot Studio Connector benötigt:

  1. Öffne Copilot Studio und wähle deinen Copilot.
  2. Gehe zu Einstellungen → Aktionen → Connector hinzufügen.
  3. Wähle Benutzerdefinierter Connector und trage ein:
    • Endpunkt: {{ base_url }}/mcp
    • Authentifizierung: API-Key / Bearer Token
    • Header: Authorization: Bearer DEIN_TOKEN
  4. Speichern und Copilot neu deployen.

Hinweis: Copilot Studio ist ein kostenpflichtiges Microsoft-Produkt. Diese Option erfordert Administratorrechte im M365-Tenant.

◆ Google Gemini CLI

Das Gemini CLI (Open Source, lokal installierbar) unterstützt MCP-Server ab Version 0.1.x. Konfigurationsdatei:

  • macOS/Linux: ~/.gemini/settings.json
  • Windows: %USERPROFILE%\.gemini\settings.json
{
  "mcpServers": {
    "obsidian-vault": {
      "httpUrl": "{{ base_url }}/mcp",
      "headers": {
        "Authorization": "Bearer DEIN_TOKEN"
      }
    }
  }
}

Im Terminal starten mit: gemini – der Vault erscheint danach als Tool.

L LM Studio Lokal

LM Studio unterstützt MCP-Server ab Version 0.3.x über die Agenten-Funktion:

  1. Öffne LM Studio und wechsle zum Tab Agent.
  2. Klicke auf MCP Servers → Add Server.
  3. Wähle den Typ HTTP (Streamable) und trage ein:
    • URL: {{ base_url }}/mcp
    • Header: Authorization → Bearer DEIN_TOKEN
  4. Verbindung testen und speichern.

LM Studio läuft vollständig lokal – deine Anfragen verlassen das Gerät nicht (außer für den Datenzugriff auf den Vault-Server).

O Ollama (mit Open WebUI) Lokal

Ollama selbst ist nur ein Modell-Runner ohne MCP-Client. Du benötigst ein Frontend, das MCP unterstützt – zum Beispiel Open WebUI:

  1. Open WebUI installieren (z. B. via Docker oder pip install open-webui).
  2. In Open WebUI: Einstellungen → Tools → MCP Servers.
  3. Neuen Server anlegen:
    • URL: {{ base_url }}/mcp
    • Header: Authorization: Bearer DEIN_TOKEN
  4. Im Chat-Fenster den Vault als Tool aktivieren.

Alternativ: mcpx als CLI-Proxy (npx @modelcontextprotocol/inspector) oder Msty als Desktop-App mit MCP-Unterstützung.

? Anderer Agent (allgemein)

Jeder MCP-kompatible Client kann diesen Vault einbinden. Der Server verwendet den HTTP-Transport (Streamable HTTP / SSE) – kein stdio. Du benötigst folgende Angaben:

Endpunkt{{ base_url }}/mcp
TransportHTTP POST (JSON-RPC 2.0)
AuthAuthorization: Bearer DEIN_TOKEN (Header)
ProtokollMCP 2024-11-05

Zum Testen der Verbindung kannst du auch den MCP Inspector verwenden:

npx @modelcontextprotocol/inspector \
  --url {{ base_url }}/mcp \
  --header "Authorization: Bearer DEIN_TOKEN"

Schritt 3 – Verfügbare Tools

Nach der Verbindung stehen folgende Tools zur Verfügung:

search_notes

Volltextsuche über Titel und Inhalt aller Notizen. Gibt bis zu 20 Treffer mit Auszug zurück.

search_notes(query: "Photosynthese")
read_note

Liest den vollständigen Markdown-Inhalt einer Notiz anhand ihres Slugs.

read_note(slug: "Biologie/Mitose")
list_notes

Listet alle sichtbaren Notizen mit Titel, Slug und Tags (Standard: max. 100).

list_notes(limit: 50)

Gruppenrechte werden automatisch angewendet – der Agent sieht nur Notizen, auf die dein Account Zugriff hat.

Beispiel-Prompts

Nützliche Fragen für die Arbeit mit fremden Inhalten – wenn du den Vault nicht selbst erstellt hast:

  • „Welche Themen oder Fachbereiche sind in diesem Vault vorhanden? Gib mir einen Überblick."
  • „Erkläre mir das Konzept [Begriff] anhand der Notizen in diesem Vault."
  • „Gibt es in den Notizen Verbindungen zwischen [Thema A] und [Thema B]?"
  • „Fasse alle Notizen mit dem Tag #[Tag] in einer strukturierten Übersicht zusammen."
  • „Welche Quellen, Literatur oder weiterführenden Hinweise werden in den Notizen über [Thema] erwähnt?"
  • „Erstelle eine Lernzusammenfassung zu [Thema] aus den vorhandenen Notizen."
  • „Wo gibt es in den Notizen inhaltliche Widersprüche oder offene Fragen zu [Thema]?"
